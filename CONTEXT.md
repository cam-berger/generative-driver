# Domain

The configurator is the local background owner of a device-discovery run. Goose, Codex and the CLI are clients. A configured agent runtime executes agents; a provider supplies the runtime's language model. These identities are distinct in benchmark results.

A stage is acquire, interpret, probe, ground, emit or reuse. One stage agent receives an assignment with admissible inputs, allowed tools, limits and required checks. The worker report is a claim. A handoff is the configurator's accepted artifact set with its hashed notes: the worker's checks, the configurator's truth-free checks and open questions. Every stage hands one off; only safety, integrity, operator and host faults stop a run. The equivalence verdict is a run's one final verdict. A benchmark verdict is an independent evaluator's result, graded once after the run; a device workflow's verdict is self-evidence, not an independent grade.

An interface model describes operations and their byte exchanges, decoders and effects. A binding selects the host resource supplied by the operator. The shared runtime executes a model against a binding. A package contains the model, runtime, reference, evidence and integrity manifest. Functional compatibility means meeting the case's observable input/output/effect contract regardless of implementation code.

Ground means comparing a claim with an independently observed channel. Fresh reuse means a new agent acts from the emitted package and its objective without development history. It is the final stage: the new agent must manipulate the device through the desired functions, and the equivalence verdict judges the required outputs and effects.

Groundtruth is evaluator-owned evidence of expected behavior, protected by password encryption and pinned hashes. Hashes identify immutable artifacts; they do not establish physical truth or restrict reads. Candidate credentials and tool access must not expose evaluator secrets. The bench harness is a benchmark's operator: it holds the evaluator password, owns an emulated case's emulator through a device provider and gives the configurator a device descriptor (binding, control endpoint, image hash and instrument units). An instrument observation is a reading of the emulated device's state; it is device evidence that workers see, never a grade.

An operator fault needs corrected user configuration; a host fault needs execution-environment repair; a model fault contradicts the candidate model. Only model faults return to interpretation as defects.
