# Selected baselines

Store only reviewed, publishable `benchmark-report/1` JSON and its Markdown summary here. Keep failed stages, unknown usage, model/runtime versions, case and toolchain hashes, budget and environment. Do not copy candidate transcripts, private credentials, absolute user paths, vendor documents or bulk historical runs.

Scripted setup/reference calibration does not belong in a model-performance table. The encrypted groundtruth bundle preserves selected reference observations. An actual agent baseline is added only after the configured agent run has completed or stopped, with its independent verdict intact.
