## Infrastructure history and limits

Two acquisition attempts were blocked by approval configuration. The initial attempt also loaded personal skill instructions; treat it as contaminated infrastructure evidence. A later grounding handoff lacked units and supporting transaction references; the repaired handoff preserved the original missing-monitor-detail limitation. A package launcher passed an unsupported read flag, causing three reuse calls to stop before protocol execution. The emulator's monitor still ran, and the conservative pending-command marker was reconciled using that distinction.

During the successful repair probe, seven advertised `probe_diff` calls failed because of an argument-alias mismatch. Independent behavioral scoring did not use this tool and passed all five checks. The release fixes the alias and checks evidence paths before dispatch, with two red-to-green regressions and 108 passing installed-wheel tests on Python 3.11/3.13. This final release fix was not executed inside the recorded baseline; the executing snapshots are identified separately.

Observations are emulated, not physical measurements. UART-over-TCP does not demonstrate physical baud or pin compatibility. During package reuse and maintenance, virtual time pauses between calls; this is not a real-time control benchmark. Maintenance changes identity only, not arbitrary firmware semantics. Extra decoded fields such as pressure and humidity were not independently qualified by this case.

Candidate assignments contained neither passwords nor plaintext reference answers. Filesystem isolation remains unverified. Oracle expected values/tolerances and internal file inventories were omitted from this selected publication; measured values, verdicts, attempts and hashes were preserved. Groundtruth remains password encrypted. See the companion context for per-attempt source/runtime identity and original/revised artifact hashes.
